# Nuclear

Nuclear is a free, open-source music player without ads or tracking. People search for any song or artist, build playlists, and listen. It runs on Windows, macOS, and Linux. The app is built with Tauri (Rust and React). Almost everything in it is driven by plugins: plugins provide metadata (search, artist and album pages), streaming sources, lyrics, playlists, dashboard content, and more. Users install plugins from the built-in plugin store.

Other features: queue with shuffle and repeat, favorites, playlists with import and export, synced lyrics, listening history and stats, built-in and custom CSS themes, a theme store, an MCP server and an HTTP API for integrations, an MPD server, remote control from a phone (Nuclear Jam), auto-updates, keyboard shortcuts, and translations into many languages.

Downloads are on the releases page. Formats:

- Windows: `.exe` installer, `.msi`.
- macOS: `.dmg` (Apple Silicon and Intel).
- Linux: `.AppImage`, `.deb`, `.rpm`, `.flatpak`.
