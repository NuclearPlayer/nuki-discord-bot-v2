# Nuki

Nuki is the Discord bot of the [Nuclear](https://github.com/nukeop/nuclear) music player server.

She answers questions about Nuclear, helps people turn bug reports and feature requests into something the maintainers can act on, and sometimes just joins the conversation. When she needs facts, she reads the Nuclear source code and looks things up on GitHub (releases, pull requests, discussions) and on the web instead of guessing.

Written in Rust with [Serenity](https://github.com/serenity-rs/serenity). The language models run through [OpenRouter](https://openrouter.ai).
